Lesson 11 · Project

  
Project: key-systems, safely

  
Files like fc38f1b744e0a932.lua.txt are key-system loaders. They all look alike:

  
loadstring(game:HttpGet("https://somewhere/script.lua"))()

  
It fetches text from a server, compiles it, and runs it. That text is completely untrusted. The pattern below is the same idea, but the code it loads is code you wrote, so it's safe.

  
Never run a loadstring you can't read line by line. Deobfuscate first, or assume it will keylog or exfiltrate from your main PC.

  

    
loader.lua

    

    

  

  
The fetch → compile → run pipeline is the only part of a key-system that matters. Servers, Discord webhooks, "authorization" — they're all theater wrapping this 3-line core.

Lesson 16 · Project

  
Click Tween — runnable test script

  
This is the same scripts/test.lua you keep on your phone, as a lesson. Tap the canvas and you tween there with precision (error 0.000). Reading any real script is just answering four questions:

  
1 · What does it build? — the GUI

  
SandboxSim.setGui(id, {text=…, x, y, w, h, color}) draws a button on the HUD. SandboxSim.on("gui", function(id) … end) is what fires when the button is actually pressed on screen. That pair — draw + handle — is the whole GUI library. The script keeps a cfg table (enabled / speed / exact / ease) and re-draws the buttons every time refreshAll() runs, so the HUD reflects the config.

  
2 · What triggers it? — click to action

  
SandboxSim.on("click", function(x, z) startTween(x, z) end). The canvas reports the world point you tapped (x, z) — no pixels, actual studs. startTween reads where you are (SandboxSim.getPlayer()), stores the target, and computes t1 = distance / speed. Tap again mid-flight and it re-targets from wherever it is.

  
3 · How does it move? — the Heartbeat loop

  
RunService.Heartbeat:Connect(function(dt) … end) runs once per frame; dt is the seconds that frame took. The script turns that into elapsed = elapsed + dt then p = elapsed / t1 — a 0→1 progress. easeFn(p) shapes the curve, and each frame the player is set to start + (target - start) * e. That lerp-on-heartbeat is the animation engine every game uses.

  
4 · When does it stop? — precision

  
At p >= 1 it snaps exactly to the clicked point, removes the target coin, and prints error 0.000. Not "close enough" — the exact click. That "snap at the end" is what makes tweens feel precise instead of drifting.

  

    
tween.lua

    

    

  

  
Break it: switch EASE to "OutElastic", set cfg.speed = 40, or add a GUI button that re-fires your last click. Every change shows up the frame you press Run.
